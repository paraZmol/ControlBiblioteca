Ruta de distribución del cliente

Carpeta del servidor donde se encuentra el ControlBiblioteca.Client.exe y el version.txt para auto-actualización de las PCs.

Cómo publicar una actualización

  1. Compilá el cliente en Visual Studio y obtené el archivo ControlBiblioteca.Client.exe.
  2. Copiá el .exe compilado a la carpeta de distribución indicada arriba, reemplazando el archivo anterior.
  3. Editá el archivo version.txt en esa misma carpeta y escribí el nuevo número de versión (ej: 4.23). Debe ser mayor al anterior o las PCs no se actualizarán.
  4. Los kioskos detectarán la nueva versión al reiniciarse y se actualizarán automáticamente.

La carpeta de compilacion suele estar en client\bin\Release\net8.0-windows\win-x64\publish\ dentro del proyecto.

Atajo de Mantenimiento

Combinación de teclas y PIN para salir del kiosco al escritorio de Windows. Solo visible para superadmin.

Modo Offline de Emergencia

Permite desbloquear una terminal cuando el servidor no es alcanzable por red. El atajo Ctrl+Alt+F11 solo se activa cuando el kiosco detecta que no hay conexion. El alumno registra su DNI y razon de uso; al recuperar la red, el sistema verifica si puede continuar.

Debe ser diferente al PIN de mantenimiento.
